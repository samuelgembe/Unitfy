## 💡 The "Why"
As a **Product Designer**, I believe that understanding how the web works at its core is essential. I built Unitfy to move beyond static design and dive into the functional side of development, focusing on:

- **Logic & Calculations:** Implementing real-time unit conversion using Vanilla JavaScript.
- **DOM Manipulation:** Creating a dynamic connection between user inputs and the displayed results.
- **Clean Architecture:** Organizing HTML and CSS to ensure the project is easy to maintain and scale.

## 🛠 Tech Stack
- **Structure:** Semantic HTML5
- **Styling:** CSS3 (Flexbox and Custom Properties)
- **Logic:** Vanilla JavaScript (ES6+)
- **Deployment:** Netlify

## 🎨 Design Decisions
- **Minimalist Interface:** Focused on utility, removing any visual clutter to prioritize the conversion task.
- **Instant Feedback:** The conversion happens as the user types, providing an effortless experience.
